# Use Case — Khách (Guest)

Khách là người chưa đăng nhập. Khách xem sản phẩm của website, chọn phiên bản, xem đánh giá và thực hiện đăng ký/đăng nhập.

| Mã | Tên Use Case | Tác nhân |
|---|---|---|
| UC01 | Xem trang chủ | Khách |
| UC02 | Xem danh sách sản phẩm | Khách |
| UC03 | Tìm kiếm, lọc và sắp xếp sản phẩm | Khách |
| UC04 | Xem chi tiết sản phẩm | Khách |
| UC05 | Chọn phiên bản sản phẩm | Khách |
| UC06 | Xem đánh giá sản phẩm | Khách |
| UC07 | Đăng ký tài khoản | Khách |
| UC08 | Đăng nhập | Khách |
| UC09 | Đăng nhập bằng Google/Facebook | Khách |

**Ghi chú:** UC01–UC06 dùng chung cho Khách, Khách hàng và Quản trị viên; trên sơ đồ có thể dùng quan hệ tổng quát hoá để Khách hàng và Quản trị viên kế thừa Khách. UC08 và UC09 cũng dùng chung cho Khách hàng và Quản trị viên.
